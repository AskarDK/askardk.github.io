01 / CONTEXT

The challenge

An event card alone does not create a community. People also need connections, conversations, reviews, notifications and tools for organizers and moderators.

02 / DEVELOPMENT

My work

Web-platform development: user and event models, backend routes, interfaces, social features and AI-generated event descriptions.

  • Profiles, interests and event creation.
  • Messaging, friend requests and notifications.
  • Event reviews, ratings and polls.
  • Organizer pages and moderation tools.
  • An AI API integration for generating event descriptions.

04 / ENGINEERING

Engineering decisions

01

Events at the center

An event connects its participants, conversations, reviews and polls, forming the core user journey.

02

Interests as part of the model

User profiles are linked to interests. The project includes logic for suggesting people based on these connections.

03

Community features need management

Alongside participant pages, the platform includes moderation and organizer actions.

What this case covers

The public repository makes the implementation available for inspection. This is a project case study; current external AI API availability and all deployment paths are not independently claimed.
